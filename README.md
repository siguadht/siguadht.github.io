# 千泷 · 个人主页

保持热忱与希望，一起奔向远方。

爱研究、爱思考，把对 AI 产品的好奇写进这里。慢慢来，比较快。

## 关于本站

- 纯静态站点，无构建步骤，直接托管在 GitHub Pages
- 黑白极简风格 + 橙色点缀，支持深色 / 浅色主题（跟随系统）
- 响应式布局，适配桌面与移动端
- 侧边栏支持文章关键词搜索（纯前端实现）

## 本地预览

```bash
cd 个人网站
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
